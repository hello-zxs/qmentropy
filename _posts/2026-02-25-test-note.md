## 1. The idea

Following Cornbleet, the refractive-index profile of a geodesic lens is

$$n(r) = \sqrt{1 + \left(\frac{r}{a}\right)^{2}}$$

a standard geodesic-lens mapping.

## 2. Checking it in code

```python
import numpy as np

a = 1.0

def simulate_light(r):
    return np.sqrt(1 + (r / a) ** 2)
```
