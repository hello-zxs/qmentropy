## 1. 理论基础

根据 Cornbleet 的理论，测地线透镜的折射率分布 $n(r)$ 为：

$$n(r) = \sqrt{1 + \left(\frac{r}{a}\right)^{2}}$$

这是一个典型的 Geodesic Lens 映射。

## 2. 代码验证

```python
import numpy as np

a = 1.0

def simulate_light(r):
    return np.sqrt(1 + (r / a) ** 2)
```
